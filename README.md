 Wajbat Alharamain App | تطبيق وجبة الحرمين

About the Project | عن المشروع

Wajbat Alharamain is a mobile application developed as part of an academic graduation project. It aims to facilitate meal requests and donations for Hajj and Umrah visitors through a simple and user-friendly experience.

The application connects beneficiaries with restaurants and meal providers, helping organize meal requests, donations, and delivery processes.


تطبيق وجبة الحرمين هو جزء من مشروع تخرج أكاديمي، يهدف إلى تسهيل طلب الوجبات والتبرع بها لضيوف الرحمن من حجاج ومعتمري بيت الله الحرام.

يربط التطبيق بين المستفيدين والمطاعم ومقدمي الوجبات، ويساعد على تنظيم طلبات الوجبات والتبرعات وعمليات التوصيل.

 Main Features | المميزات الرئيسية

- User Registration and Login | تسجيل الدخول وإنشاء الحساب.
- Browse Available Meals | استعراض الوجبات المتاحة.
- Meal Donations | التبرع بالوجبات.
- Place Meal Orders | طلب الوجبات.
- Order Tracking | متابعة الطلبات.
- Payment Options | خيارات الدفع.
- User Account Management | إدارة حساب المستخدم.

Technologies Used | التقنيات المستخدمة

- Flutter
- Dart
- REST API
- Backend Integration

 Backend | الواجهة الخلفية

The application is connected to the Wajbat Alharamain backend through REST API.
